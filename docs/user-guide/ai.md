# AI 分析

Serpent 的 AI 分析默认连接你自己的云端 AI 服务，也可以连接在**本机或 WSL 中运行**的本地模型。云端方案需要准备服务商账号、API Key、支持图像输入的模型，并确认服务费用；本地方案不需要账号和 API Key。

## 配置

Windows 从左上角 `主菜单 → 设置 → AI` 打开，macOS 从系统菜单打开 `设置 → AI`。

![AI 配置界面](../assets/ui/AI-config.png)

### 连接服务

- `API 格式` 选择服务商的接口类型，可选 `DashScope Multimodal (native)`、`OpenAI Chat Completions`、`OpenAI Responses`、`Anthropic Messages`、`Gemini Native`、`Local model (WSL / OpenAI-compatible)`。使用中转站时按中转站的接口说明选择。
- `请求地址` 通常可以留空；使用中转站或自建网关时，填写服务商提供的地址。DashScope 原生接口使用 `/api/v1`。
- `API Key` 粘贴服务商生成的密钥。眼睛图标可以暂时查看；保存后不会显示完整密钥，需要更换时重新输入。
- `模型` 填写服务商提供的视觉模型名称。输入有效密钥后可以读取模型列表，读取失败时直接手动填写。
- `语言` 是单选项，可选中文、English、日本語或 한국어；描述和标签会使用所选语言。
- 点击 `测试连接`，成功后点击 `保存配置`。

不要把 API Key 写入脚本、插件、截图、问题反馈或 MCP 配置。

### 使用本地模型（含 WSL）

选择 `Local model (WSL / OpenAI-compatible)` 后，AI 分析请求会发给你自己启动的本地推理服务，不经过任何云端服务商，也不需要 API Key。

1. 在 WSL 或 Windows 中启动一个提供 **OpenAI 兼容接口**且**支持图像输入**的服务：
   - Ollama：`ollama serve`，然后 `ollama pull qwen2.5vl:7b`
   - LM Studio：打开 Local Server
   - llama.cpp：`llama-server -m <模型.gguf> --mmproj <视觉投影.gguf> --host 0.0.0.0`（默认端口 8080，可用 `--port` 改）
   - vLLM：`vllm serve Qwen/Qwen2.5-VL-7B-Instruct`
2. 选择 `Local model (WSL / OpenAI-compatible)` 后 Serpent 会自动探测一次常用端口，并把唯一命中的服务填入 `请求地址`；也可手动点击 `Ollama` / `LM Studio` / `llama.cpp` / `vLLM` 预设，或点击 `检测本地/WSL 服务` 重新探测后逐个点选。
3. 确认 `模型` 支持视觉输入。若本地服务自己声明了能力（llama.cpp 与较新的 Ollama 会在模型列表里返回 `capabilities`），Serpent 直接采用；只有服务未声明时，才按模型名称判断并提示「可能不支持图像」。
4. `API Key` 留空，点击 `测试连接`，成功后 `保存配置`。`测试连接` 测的是当前界面填写的内容，不需要先保存。

**关于 WSL 的连通性**

- WSL2 会把 Windows 侧的 `127.0.0.1` 转发给 WSL 内监听 `0.0.0.0` 的服务，因此 `http://127.0.0.1:<端口>/v1` 通常可直接使用（开启 WSL 镜像网络模式时同样适用）。
- 如果服务只监听 `127.0.0.1`（WSL 内部回环），Windows 无法转发。请改为监听 `0.0.0.0`，例如 `OLLAMA_HOST=0.0.0.0 ollama serve`，或给 llama.cpp 加 `--host 0.0.0.0`。
- 若无法改为 `0.0.0.0`，可使用 `检测本地/WSL 服务`：它会读取 `wsl hostname -I` 得到的发行版地址并逐个探测，可直接点击填入。注意该地址在 WSL 重启后会变化，因此优先使用 `127.0.0.1`。
- 检测结果会显示服务**自己**声明的名字（如 `llama.cpp`、`vLLM`、`Ollama`），而不是端口预设的品牌名；无法识别时显示「OpenAI 兼容服务」。端口预设按钮（如 `vLLM (8000)`）只是「填入该端口」的快捷方式，不代表 8000 上一定是 vLLM。
- 检测功能只在 Windows 上查询 WSL；macOS / Linux 上仍会探测本机回环端口。
- 端口不是常用端口时不会被自动探测到，请直接手填 `请求地址`（例如 `http://127.0.0.1:8000/v1`）。

**本地模型的注意事项**

- AI 分析会发送图像（视频发联系表、3D 模型发四视图），文本模型无法完成分析。
- 本地服务通常不校验密钥，因此 `API Key` 可留空；如果本地服务前面挂了需要鉴权的反向代理，则照常填写。
- 本地推理速度取决于显卡与模型规模，建议在 `高级设置` 中下调 `并发分析上限`（例如 1–2），避免显存耗尽。
- 本地模型对 OpenAI 的 `json_schema` 结构化输出支持不一，Serpent 会自动回退到更通用的返回格式；若模型输出不稳定，可改用更大的视觉模型或调整 `自定义描述提示词`。

### AI 写入开关

- `描述`：生成画面内容、风格和氛围说明。
- `标签`：生成类型、风格、主题和视觉特点关键词。
- `AI 评分`：按照评分标准生成 1–5 分的参考评分。
- `强制使用已有标签`：只从当前已有标签中选择，不新增标签。

AI 内容与人工内容分开保存，人工描述、标签和评分不会被覆盖。

#### 描述的生成口径

AI 生成的内容是**资产编目**，不是内容审核。所有供应商的提示词都内置同一条准则：

- **如实描述**：写画面中实际存在的主体、场景、动作、物件、文字与视觉特征，画面呈现什么就描述什么。
- **不因题材敏感而模糊化**：即使画面涉及隐私、成人、暴力、医疗、证件或个人信息等内容，也照实描述；不会用「隐私内容」「敏感图片」「不便描述」之类的笼统说法代替，不会省略、代称或拒绝输出。
- **保持中性**：只作事实陈述，不做道德或合规评判，也不会在描述里附加免责声明、内容警告或与画面无关的推测。
- **评分只看画面质量**：`AI 评分` 按 `评分标准` 给出，不因题材敏感而抬高或压低。

因此含敏感内容的资产，其 AI 描述也会写得具体。这些内容只写入你自己的资源库。

### 高级设置

- `并发分析上限`：默认 16，范围 1–32；遇到服务商限流时调低。
- `分析图像最大边长`：默认 2048 px，范围 512–4096；只会缩小，不会放大。
- `最大标签数`：默认 8，范围 1–32。
- `中文描述上限`：默认 100 字，范围 20–500。
- `英文描述上限`：默认 60 词，范围 10–200。
- `输出风格`：`正常`、`精简`、`严谨`。
- `评分标准`：说明 1–5 分分别代表什么。
- `自定义描述提示词`：补充描述重点，例如“重点说明构图和光线”。
- `自定义标签提示词`：约束标签分类。不要在提示词中写密钥或其他秘密。

### 自动分析

接受免责声明并打开 `新增资产自动进行 AI 分析` 后，新导入的图像、视频和 3D 模型会在后台分析；该开关默认关闭，关闭它不会删除已有 AI 内容。

## 支持的资产

- 图像和 RAW：发送缩放后的图像。
- 视频：发送带时间标记的联系表，不上传原始视频。
- 3D 模型：发送四视图图像。
- 音频、文本和其他不支持的格式：不会进入 AI 分析。

## 手动分析和结果

在资产右键菜单选择 `AI 分析`，也可以对多选资产使用批量操作。`AI 分析未分析项` 会跳过已有结果；需要重新分析时使用普通的 `AI 分析`。

![从资产右键菜单启动 AI 分析](../assets/ui/AI-analyze-menu.png)

结果显示在资产 Inspector 的 AI 区域。重新分析成功后会替换当前 AI 结果，不保留旧版本；清除 AI 内容不会删除人工内容或标签实体。

## 任务和失败处理

从 `窗口 → 后台任务` 查看排队、运行、暂停、失败和已完成的 AI 任务，可暂停、继续、取消和重试失败项。网络、限流和超时通常可以直接重试；配置、权限、额度或文件格式问题需要先修正。

视频联系表或缩略图未就绪时，先在后台任务中重试媒体生成，再重试 AI。失败提示会显示简短原因。

## 隐私和费用

Serpent 不上传整个资源库，也不提供 AI 搜索。只有明确提交的可分析资产才会发送给所选服务商；启用前请确认服务商的隐私条款和费用。

AI 描述会如实记录画面内容，包括其中的敏感或私密细节；这些结果只保存在你的本地资源库中。

使用本地模型时，这些内容只会发送给你自己的推理服务，不经过第三方；请自行确认模型许可与本地资源占用。
